# Swiggy Data Analysis

## Project Overview
This project explores Swiggy food delivery data using Python. It uses data analysis and visualization techniques to understand meal prices, customer ratings, food cuisines, preparation times, and rider distances across different cities.

## Objectives
- Analyze food orders across different cities.
- Explore customer ratings and cuisine types.
- Calculate average and median meal prices.
- Compare food preparation times in Delhi and Mumbai.
- Understand the distribution of meal prices and rider distances.
- Visualize patterns and relationships in the dataset.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data exploration and descriptive statistics
- City-wise and cuisine-wise analysis
- Mean, median, mode, range, variance, and standard deviation
- Histograms and box plots
- Bar plots and scatter plots
- Correlation heatmap
- Comparison of meal prices and preparation times across cities

## Dataset
The notebook uses a dataset named `Swiggy_Analysis.csv` with columns such as:
- `City`
- `Cuisine`
- `Customer_Rating`
- `Avg_Meal_Price_INR`
- `Preparation_Time_Min`
- `Rider_Distance_KM`

**Note:** Add the CSV dataset to the repository if you have permission to share it. The notebook currently loads it from `/content/Swiggy_Analysis.csv`, so update the file path when running it locally.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries:

   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```

3. Place `Swiggy_Analysis.csv` in the appropriate folder.
4. Open `swiggy-data-analysis.ipynb` in Jupyter Notebook or Google Colab.
5. Update the dataset file path if required.
6. Run the notebook cells in order.

## Project Outcome
This project demonstrates how Python can be used to explore food delivery data, compare different cities, summarize numerical information, and create visualizations that help understand data patterns.
